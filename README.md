# Proyecto BookEx
BookEx es una aplicación de reseñas de libros en la que el usuario puede guardar información de diferentes libros dejando una reseña y una puntuación, además de crear listas donde poder guardar y clasificar los libros.

Proyecto intermodular de 2º de DAM. IES Abastos 2026.
